# جزيرة أسرار الحياة
مغامرة تعليمية فلسطينية عربية للصف السابع، الوحدة الأولى «خصائص الكائنات الحية». إعداد المعلمة: أ. آلاء محسن كلاب.

## التشغيل
يتطلب Node.js 22 أو أحدث.

```sh
npm ci
npm run dev
npm run test
npm run build
```

React + TypeScript + Vite، واجهة RTL، بيانات محلية دون حسابات أو خدمات مدفوعة. المصدر منفصل في src/data، والمحاكاة في src/engine وsrc/components.

## النشر
المسار الأساسي `/Biology/`. ينشر سير العمل GitHub Pages من main. يجب اختيار GitHub Actions من Settings → Pages. رفع المصدر ليس دليل نجاح النشر؛ راجع سير العمل والرابط الفعلي.

## حالة المحتوى
راجع [سجل التنفيذ](docs/STATUS.md). لم يُعتمد المحتوى بعد وفق الكتاب المرفق لتعذر تنزيله بسبب حد الحجم. تُستكمل المراجعة بعد وصول صفحات الوحدة.

## الخصوصية
الاسم والنتائج محفوظة في المتصفح على الجهاز الحالي. لا مزامنة بين الأجهزة. تتيح لوحة المتابعة تصدير نسخة احتياطية واستعادتها.
