# حديقة أسرار الحياة 🌿

> الواجهة الحالية: لوحة تعلم حديثة ببحث وسبعة دروس مفتوحة، ومسار شرح وتجربة وتقويم لكل مفهوم. للمحاكاة مساحة عمل واسعة، ومقارنة نتائج محفوظة، وتكبير للتفاصيل. لا نظام كتاب أو تقليب. [تقرير التطوير والتحقق](docs/EXPERIENCE-REDESIGN.md). تقارير الإصدارات السابقة سجلات تاريخية.

مغامرة تعليمية فلسطينية تفاعلية للوحدة الأولى «خصائص الكائنات الحية»، العلوم والحياة، الصف السابع الأساسي. إعداد المعلمة **أ. آلاء محسن كلاب**. الشعار: **اكتشف، جرّب، تعلّم، وانطلق!**

## الوظائف الحالية
- سبعة دروس: التغذية، الأيض، النمو، الحركة، الإخراج، الاستجابة، التكاثر.
- 34 مفهومًا؛ لكل مفهوم شرح ومثال، ثم تجربته عند الحاجة وتقويم مباشر، دون قسم أنشطة أو تقويم تكويني مستقل.
- 23 محاكاة علمية بمشاهدة وتجريب ومتغيرات قابلة للتحكم، مع حفظ نتيجة مرجعية ومقارنتها بإعداد آخر وتكبير تفاصيل الرسم.
- خمسة أسئلة تشخيصية لكل درس، وبعديات وبنوك إعادة مكافئة، وإنفوجرافيك صامت قبل البعدي، وشهادات مبنية على الإنجاز.
- شخصية فلسطينية موحدة بتلميحات مكتوبة، و17 مؤثرًا محليًا مع الكتم ومستوى الصوت؛ حُذفت أصوات فتح الكتاب وتقليب الورق.
- RTL، واجهة متجاوبة، وقائمة جانبية غير منبثقة، وتخزين محلي مع تصدير واستعادة.

يبقى التنقل حرًا، وتبقى الاختبارات والشهادات والتقدم محفوظة. صورة المعلمة وتسجيلاتها الأصلية غير مضبوطة في الأصول الحالية؛ لم تُنشأ بدائل مصطنعة. قيود مطابقة طبعة المرجع موثقة في [مراجعة المصدر](docs/SOURCE-REVIEW.md).

## التشغيل
يتطلب Node.js 22 أو أحدث.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

مسار التطبيق `/Biology/`، لذلك افتحي هذا المسار في خادم التطوير والمعاينة.

## بنية المشروع
```text
src/data/          دروس وأسئلة ومواءمة وإعدادات أصول وصوت
src/engine/        نماذج علمية وقواعد تكيف وإتقان وتحقق بيانات
src/components/    مختبر واختبارات وأنشطة وصوت وجزيرة ومشروع
public/audio/      تسجيلات المعلمة منظمة حسب الدرس وموسيقى اختيارية
public/images/     الصور الأصلية عند إضافتها
public/fonts/      Noto Sans Arabic بترخيص SIL OFL
scripts/           إنشاء Service Worker من ناتج البناء
 tests/            اختبارات منطق وتفاعل ورحلة طالب كاملة
 docs/             ADDIE ومراجعة المصدر وحالة العمل وضمان الجودة
```

## GitHub Pages
المستودع الأصلي العام: [Alaamohsen-22/Biology](https://github.com/Alaamohsen-22/Biology). الفرع الافتراضي والمستخدم main.

اختاري **Settings → Pages → Build and deployment → Source → GitHub Actions**. سير العمل يختبر ويبني ثم ينشر من main؛ يمكن تشغيله يدويًا. رُفض التفعيل الأول عبر التكامل 403، ثم فعّلت المعلمة المصدر يدويًا ونجحت إعادة النشر. تم التحقق من الرابط المباشر والموارد؛ رفع المصدر ونشره مرحلتان منفصلتان.

ضبط Vite وService Worker تحت `/Biology/`. النشر استضافة ملفات ساكنة بلا خادم رفع دائم أو خدمات مدفوعة أو مفاتيح API.

## الخصوصية والبيانات
الاسم والنتائج في LocalStorage على الجهاز الحالي. لا حسابات ولا مزامنة ولا إرسال نتائج تلقائيًا للمعلمة. استخدمي التصدير والاستعادة لنقل التقدم. إعدادات المعلمة محلية وليست لوحة حسابات محمية. الملفات المضافة إلى المستودع العام ستكون متاحة للعموم.

## الأصول والترخيص
رسوم SVG ولحن الخلفية أنشئا لهذا المشروع. ترخيص الخط محفوظ في public/fonts/OFL.txt. لا يضم المستودع نسخة الكتاب أو صور المعلمة أو تسجيلاتها لعدم توفرها؛ لا تضاف أصول شخصية أو كواشف حقيقية أو تجارب تشريح إلى الأنشطة.
