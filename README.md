## الوظائف المنفذة
- غلاف وجزيرة SVG بطابع فلسطيني، خريطة سبع محطات، تسجيل اسم محلي.
- التغذية، الأيض، النمو، الحركة، الإخراج، الاستجابة، التكاثر؛ لكل درس المراحل العشر و5 أسئلة قبلية و7 بعدية وأهداف وشرح وأنشطة وتكوين وعلاج وإثراء.
- 23 مشهدًا علميًا، لكل منها مشاهدة تلقائية وتجريب بمتغيرات ودفتر ملاحظات. النتائج نوعية والزمن الطويل مسرع، لا قياسات مخبرية.
- بنك إعادة موازٍ من 49 سؤالًا جديدًا، ومعيار إتقان قابل للتعديل؛ فتح صفحة لا يمنح نجومًا.
- مشروع دبال، اختبار شامل من 15 سؤالًا، لوحة تقدم وتصدير واستعادة، وشهادة بطباعة أو حفظ PDF من المتصفح.
- RTL، تصميم متجاوب، تقليل حركة، تباين وخط ووضع داكن، بدائل للمس، ومساعد نصي صامت.
- ربط تسجيلات المعلمة الحقيقية دون صوت صناعي. موسيقى رقمية أصلية اختيارية بلا كلام. كل الأصول المستخدمة محلية، مع إعداد cache أساسي بعد الزيارة الأولى.

**حالة التسليم:** الوظائف الأساسية اجتازت الاختبارات الآلية والبناء، لكن المشروع ليس معتمدًا نهائيًا وفق معايير المعلمة: الصورة والشخصية والتسجيلات الأصلية منتظرة، ومعاينة الهاتف والمتصفح لم تتحقق بعد. نجح نشر GitHub Pages والتحقق من الموارد. [سجل الإنجاز](docs/STATUS.md) يوضح ما اكتمل وما بقي.

## التشغيل
يتطلب Node.js 22 أو أحدث.

```sh
npm ci
npm run dev
npm test
npm run build
npm run preview
```

مسار التطبيق `/Biology/`، لذلك افتحي هذا المسار في خادم التطوير والمعاينة.

## بنية المشروع
```text
src/data/          دروس وأسئلة ومواءمة وإعدادات أصول وصوت
src/engine/        نماذج علمية وقواعد تكيف وإتقان وتحقق بيانات
src/components/    مختبر واختبارات وأنشطة وصوت وجزيرة ومشروع
public/audio/      تسجيلات المعلمة منظمة حسب الدرس وموسيقى اختيارية
public/images/     الصور الأصلية عند إضافتها
public/fonts/      Noto Sans Arabic بترخيص SIL OFL
scripts/           إنشاء Service Worker من ناتج البناء
 tests/            اختبارات منطق وتفاعل ورحلة طالب كاملة
 docs/             ADDIE ومراجعة المصدر وحالة العمل وضمان الجودة
```

## GitHub Pages
المستودع الأصلي العام: [Alaamohsen-22/Biology](https://github.com/Alaamohsen-22/Biology). الفرع الافتراضي والمستخدم main.

اختاري **Settings → Pages → Build and deployment → Source → GitHub Actions**. سير العمل يختبر ويبني ثم ينشر من main؛ يمكن تشغيله يدويًا. رُفض التفعيل الأول عبر التكامل 403، ثم فعّلت المعلمة المصدر يدويًا ونجحت إعادة النشر. تم التحقق من الرابط المباشر والموارد؛ رفع المصدر ونشره مرحلتان منفصلتان.

ضبط Vite وService Worker تحت `/Biology/`. النشر استضافة ملفات ساكنة بلا خادم رفع دائم أو خدمات مدفوعة أو مفاتيح API.

## الخصوصية والبيانات
الاسم والنتائج في LocalStorage على الجهاز الحالي. لا حسابات ولا مزامنة ولا إرسال نتائج تلقائيًا للمعلمة. استخدمي التصدير والاستعادة لنقل التقدم. إعدادات المعلمة محلية وليست لوحة حسابات محمية. الملفات المضافة إلى المستودع العام ستكون متاحة للعموم.

## الأصول والترخيص
رسوم SVG ولحن الخلفية أنشئا لهذا المشروع. ترخيص الخط محفوظ في public/fonts/OFL.txt. لا يضم المستودع نسخة الكتاب أو صور المعلمة أو تسجيلاتها لعدم توفرها؛ لا تضاف أصول شخصية أو كواشف حقيقية أو تجارب تشريح إلى الأنشطة.

### مراجعة الكتاب بصفحة واحدة
تحديث التمهيد والاختبار القبلي والأهداف لدرس التغذية، مع إطار كتاب بصفحة واحدة وحفظ حالة التفاعلات. تفاصيل النطاق والمواءمة والاختبارات والقيود في [تقرير المراجعة](docs/SINGLE-PAGE-BOOK-REVIEW.md). إعداد وسائط المرشدة المستقبلية في [دليل الوسائط](public/guide/README.md). هذه النسخة في فرع مراجعة، ولا تنشر إلا بعد الموافقة ودمجها في `main`.

### حصص العلوم داخل الكتاب
النسخة الأحدث تعيد تنظيم الدروس السبعة في فهرس مفاهيم، مع شرح وتجربة وتقويم لكل مفهوم، وسبعة إنفوجرافيكات صامتة قبل البعدي. تبقى صفحة كتاب واحدة واتجاه RTL والتقدم المحلي. [تقرير التطوير والمواءمة والقيود](docs/CONCEPT-BOOK-REVIEW.md) هو مرجع النطاق الحالي، ويحل محل تفاصيل المراحل العشر والأنشطة المستقلة الواردة في تقارير الإصدارات القديمة.
