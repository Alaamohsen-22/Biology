## الدبال والتركيب والاستكشاف
حاوية الدبال أضيف إليها عمق الحواف وفتحات تهوية ومظهر المواد المتحللة، مع بقاء نموذج التحلل والزمن الافتراضي؛ أصبح اختيار المواد والتهوية والرطوبة والزمن والملاحظات محفوظًا محليًا. أضيف انتقال زمني واكتشاف عند اكتمال التحلل. تركيب الجهاز البولي والاستكشافات يعيدان استخدام الرسوم المحدثة وتكبيرها. البطاقات والاختبارات وأسئلة الوحدة لم تحذف ولم تتغير درجاتها.

## الواجهة والتجريب
- هدف علمي محدد وتوقع محفوظ قبل الرسم؛ أدوات تنفيذ فعلية تقبل النقر/لوحة المفاتيح واللمس، ثم ملاحظة واستنتاج محفوظان وتفسير عند الطلب.
- لم يعد تغيير المنزلق يقفز إلى النتيجة؛ يعيد الزمن إلى البداية ويجهز ظروف التشغيل. آخر أداة من تسلسل التجهيز تبدأ التجربة؛ ويمكن تشغيلها يدويًا أو تعديل الظروف أو إعادة المحاولة.
- كل أداة تضبط مدخلًا علميًا في النموذج. في التجارب التي تتطلب إضافة مواد يبدأ التجريب دون المواد: ماء/ضوء/غاز، خميرة/سكر، نبات/غطاء تربة، كاشف أو أمشاج؛ تظهر نتيجة الإضافة بعد تنفيذها وتشغيل العملية. أدوات اختيار العينة أو العملية تضبط الاختيار وتؤكده بدل فرض إخفاء عضو موجود طبيعيًا. يمكن اختبار غياب المواد أو اختلاف الظروف من المنزلقات.
- خطوة حالية وشريط تقدم؛ التفاصيل العلمية والقيود الزمنية ومعلومات التمثيل المجهري داخل معلومات التجربة. تنبيه سلامة الخبز والمنعكس الافتراضي محفوظان.
- التكبير مستقل، مع إغلاق وEscape وحصر Tab داخله. عند التكبير على هاتف ضيق يمكن تمرير الرسم المكبر؛ الصفحة العادية لا تحتاج تمريرًا أفقيًا.
- المساعدة الفلسطينية تتلقى اسم التجربة والأداة والتلميح والخطأ والنجاح، وتظل صامتة قابلة للإخفاء خارج مساحة الرسم.

## الصوت
مدير مركزي موجود طُور دون استبدال تسجيلات المعلمة أو صوت الجزيرة. 13 مؤثرًا أصليًا محليًا؛ ثلاثة جديدة خفيفة: drop.wav / discover.wav / time.wav. ملفات PCM أحادية القناة، دون API أو صوت بشري مولد. drop للقطرات عند وصولها للسائل، discover لظهور النتيجة وليس إتقانًا، time لتقدم الأيام. مؤثر النجاح منفصل ومقيد بصحة الاستنتاج/النشاط.

في لوغول تقع القطرات خلال مرحلة الإضافة (26–48% من العرض)، ويبدأ تغير اللون بعد اكتمال الإضافة (50–75%)؛ الاكتشاف عند وضوح اللون. لا ينتقل العرض تلقائيًا إلى المقارنة قبل نهاية تغير اللون. الحركة والزمن تعليميان، لا محاكاة كيميائية كمية.

توقف مؤثرات المشهد عند مغادرته. التسجيلات الطويلة تملك قناة الصوت فتمنع مزاحمة المؤثرات. يظل الكتم والمستوى وقيود المتصفح محترمة.
