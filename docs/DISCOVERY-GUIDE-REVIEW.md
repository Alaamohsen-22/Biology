## المنفذ
- صفحة «كيف يصنع النبات غذاءه؟»: توقع مثبت قبل المحاكاة، ثم تجربة ضوء/ماء/ثاني أكسيد الكربون، ثم ملاحظة واستنتاج، ثم تفسير ومقارنة وحصيلة. التفسير لا يظهر إلا بطلب الطالب، ولا تمنح الإجابات النصية إتقانًا آليًا.
- نموذج البناء الضوئي يوقف جميع مؤشرات العملية عند غياب عامل أساسي ويحافظ على شكل النبات. عند توفر العوامل تظهر حركة انتقال الماء والغازات والضوء وإنتاج الغذاء؛ حالات متباعدة عند تقليل الحركة. تحسن تمثيل الأكسجين في الرسم المشترك حتى لا يُحجب كليًا عند توفر العوامل بكمية منخفضة.
- حفظ مستقل لمسودات الاستكشاف والاختبارات والمطابقة والترتيب والتكويني وتركيب الجهاز البولي محليًا، دون تعديل مفاتيح تقدم الطالب أو حساب الدرجات. المسودات لا تُمنح درجة لمجرد استعادتها، ويمكن مسحها بإعادة النشاط. لا تتضمن صادرات التقدم القديمة هذه المسودات الإضافية.
- أزرار تنقل مزخرفة بتطريز مبسط وألوان العلم متناسقة مع ألوان الموقع؛ السابق أهدأ والتالي أخضر، واتجاه الأسهم RTL. القائمة الجانبية قابلة للطي على الهاتف. يبقى التنقل حرًا.
- مساعدة معلمة فلسطينية خيالية SVG، ليست صورة المعلمة أو بديلًا لملامحها. ملابس مطرزة، واجهة إظهار وإخفاء، تلميح متدرج، فهمت وشكرًا، دون صوت أو API خارجي. تتغير التلميحات بحسب الدرس والمرحلة، وفي الاستكشاف بحسب التركيز وتشغيل التجربة والعوامل، وفي المختبر بحسب التجربة والأداة المختارة. لا تفتح النافذة تلقائيًا.
- صوت الجزيرة يستخدم الملف الأصلي audio/ambience/island.wav دون تغيير. محاولة تشغيل واحدة عند دخول الخريطة، وزر بديل عند منع المتصفح، وإعادة وكتم، واحترام الكتم العام والمستوى. تُلغى طلبات التشغيل المعلقة ويوقف التسجيل عند المغادرة؛ مؤثرات قصيرة لا تزاحم التسجيل الطويل.
- تنظيف التسجيلات والموسيقى عند مغادرة مكونها حتى لا تستمر في مرحلة أخرى. لا صوت اصطناعي للمعلمة أو للشخصية.

- البناء: نجح TypeScript وVite وإنشاء التخزين المؤقت. نجح git diff --check. لم تتغير ملفات بيانات الدروس والأسئلة أو قواعد الإتقان أو الأصول أو إعداد النشر.
