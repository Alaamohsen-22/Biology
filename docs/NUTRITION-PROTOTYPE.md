# نموذج التغذية للمراجعة

هذا الفرع ينفذ طلب النموذج الأولي لدرس واحد قبل تعميمه. لا يدمج في `main`، ولا يغيّر GitHub Pages قبل موافقة المعلمة.

## التجربة الجديدة

- غلاف أقصر وفهرس دروس مفتوح دون بوابات إكمال.
- تمهيد بستان الزيتون: اختيار الجذور والأوراق والشمس، وتوقع محفوظ وغير محسوب في العلامة.
- التغذية وأنواعها: رسوم أصلية SVG للزيتون والأرنب والفطر، وتصنيف مع تصحيح وشرح واحتفال عند إتمام المجموعة فقط.
- البناء الضوئي: مخطط مدخلات/نواتج قابل للاستكشاف، وترتيب بطاقات بالمراحل الأصلية المعتمدة؛ تبقى تجربة الضوء والماء وثاني أكسيد الكربون بوضعَي المشاهدة والتجريب.
- لوغول: اختيار النشا أو الماء، إضافة الكاشف، سقوط القطرات والتحول التدريجي، ثم استنتاج؛ تبقى التجربة المقارنة الكاملة.
- التغذية غير الذاتية: رسوم عفن الخبز والقمل وتصنيف الترمم والتطفل. تبقى تجربة ظروف العفن الافتراضية.
- غذاء الحيوانات: مقارنة بصرية وتصنيف آكل الأعشاب/اللحوم/القارت.
- خلاصة بصرية بخمس لوحات ورسوم علمية؛ لا صوت داخلها.
- الشرح التفصيلي والأمثلة في «اعرف أكثر»، وسؤال الفهم في كشف مستقل داخل المفهوم، دون صفحة أنشطة مستقلة.
- المرشدة الفلسطينية نفسها في جميع مواضع النموذج، مع تلميحين قصيرين لكل مفهوم، وإغلاق اختياري.

التعريفات والمراحل الصحيحة والأسئلة الأصلية ومعيار الإتقان محفوظة. يعتمد المحتوى على بيانات `curriculum.ts` و`lessons.ts` الحالية. لا يتغير محتوى الدروس الستة الأخرى أو نماذجها أو درجاتها. حدّ توثيق المرجع الأصلي موضح في `SOURCE-REVIEW.md`؛ لم يجر ادعاء قراءة صفحات أصلية غير متاحة.

## الصوت

المؤثرات الفعلية الموجودة موصولة بالنقر والاختيار والقطرات والنتيجة والنجاح. يدير القناة المدير المركزي الحالي، مع الكتم ومستوى الصوت وأولوية التسجيلات. لا تساوي المؤثرات تسجيلات كلام بشري.

**لا توجد تسجيلات بشرية عربية للمرشدة أو عبارات التشجيع في الملفات المتاحة. لذلك الصوت الطبيعي غير مكتمل.** لم تستخدم خدمة مدفوعة أو صوتًا آليًا بديلًا. `public/config/nutrition-voice.json` فارغ عمدًا؛ لا تظهر أزرار استماع وهمية. لإكماله: أضيفي التسجيلات المرخّصة إلى `public/audio/nutrition` ثم انسخي إعدادات المثال المطابقة. يبطل البناء عند إدراج مسار مفقود أو ملف غير صوتي. التفاصيل في README ذلك المجلد. يمكن ربط خدمة صوت لاحقًا بعد تحديد الحساب والتكلفة، دون أسرار في الموقع الثابت.

## الاختبار

- اختبار رحلة آلي عبر الدروس السبعة، 23 محاكاة، الأسئلة، اختبارات الدروس والوحدة، الشهادات والحفظ بعد إعادة التشغيل.
- ستة اختبارات جديدة: التصنيف الخاطئ/الصحيح، الحفظ وعدم تكرار الإنجاز، المخطط العلمي، تدرج لوغول واختلاف الضابط، لوحات الإنفوجرافيك، توقع التمهيد والتنقل والمرشدة.
- اختبارات الصوت الحالية تتحقق برمجيًا من ملفات WAV والأحداث والأولوية والكتم وتنظيف الوسائط؛ لا تثبت جودة السماع البشري أو توفر تسجيلات عربية.
- نجح بناء TypeScript/Vite للنسخة تحت `/Biology/` وللمعاينة تحت `/`.
- تعذر تشغيل معاينة المتصفح المحلية: `sites-preview` فشل في اتصال relay. لا يعد نجاح البناء دليلًا على معاينة الهاتف أو سماع الصوت؛ يتم توثيق أي تحقق مرئي لاحق هنا.

## التشغيل والمعاينة

```sh
npm ci
npm test
npm run build
npm run build:review
```

`build` يحفظ إعداد GitHub Pages `/Biology/` ويولّد مخبأ العمل دون اتصال. `build:review` يبني في `dist-review` بمسار جذر للمعاينة المنفصلة ولا يسجل service worker الخاص بـ Pages.

التقدم محلي لكل أصل/متصفح؛ لن ينتقل تلقائيًا من GitHub Pages إلى أصل المعاينة. لم تمسح بيانات الطالب على الموقع الأصلي.
