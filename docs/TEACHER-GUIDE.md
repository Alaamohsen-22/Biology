# دليل المعلمة

## ربط الصور دون تغيير الوجه
ضعي الصورة الأصلية في public/images/teacher.jpg، ثم اكتبي في src/data/assets.json:

```json
{"teacherPortrait":"images/teacher.jpg","companion":"images/companion.png"}
```

لا تضعي مسار الشخصية إلا بعد إضافة ملفها. الصور تظهر كما هي داخل إطار بصري؛ لا معالجة للوجه. المساعد نصي صامت. الملفات المضافة للمستودع العام تصبح متاحة لزوار الموقع.

## تسجيلاتك الحقيقية
لكل درس مجلد public/audio/lesson-1 إلى lesson-7 وتعليمات داخله. النصوص الموازية تظهر في بطاقات الصوت. سجلي intro، explanation، simulation، activity، summary. تسجيل الترحيب في public/audio/welcome/welcome.mp3.

انسخي فقط المفاتيح ذات الملفات الموجودة من src/data/audio.example.json إلى src/data/audio.json. مثال:

```json
{"0.welcome":"audio/welcome/welcome.mp3","1.intro":"audio/lesson-1/intro.mp3"}
```

ارفعي الملفات والتعديلات إلى main، وانتظري نجاح سير العمل. لا يوجد رفع ملفات دائم من المتصفح أو قاعدة بيانات سحابية. لا تكتبي مفاتيح API أو أسرارًا في هذا المشروع. الموسيقى الاختيارية أصل رقمي بلا كلام، منفصلة عن تسجيلاتك، وتتوقف من إعداد الصوت.

## المحتوى والأسئلة
src/data/lessons.ts يحتوي أهداف وشرح كل درس ومشاهد المحاكاة والأسئلة والإجابات والتفسير وربط الأهداف. أول 5 أسئلة للقبلي؛ السبعة التالية للبعدي؛ parallel بنك إعادة مكافئ مستقل. finalBank ينتج 15 سؤالًا مع تصنيف الدرس. alignment يربط الأهداف بالشرح والأنشطة والمشاهد والأسئلة. بعد التعديل شغلي npm test وnpm run build.

## النماذج
src/engine/models.ts يحسب النتائج النوعية؛ src/components/Simulation.tsx يرسم الحالات ويشغل الزمن. تعديل الرسم وحده لا يغير النموذج العلمي. المتغيرات محلية وقيمها ليست نتائج قياس. استعيني بتحكيم معلمة علوم لأي تغيير في القواعد.

## معايير الإتقان
من الترس → إعدادات المعلمة غيّري المعيار (50–100%؛ افتراضي 70%). الفتح للمعاينة لا يمنح وسامًا. إعدادات المعلمة محلية وغير محمية بكلمة مرور وليست لوحة إدارة حسابات. تشترط الشهادة إتقان الدروس والمشروع والاختبار الختامي.

## النشر
المستودع العام الحالي: https://github.com/Alaamohsen-22/Biology

من Settings → Pages → Build and deployment → Source اختاري GitHub Actions. سير العمل يبني ويختبر ويرفع artifact ثم ينشر. كل المسارات مضبوطة تحت /Biology/. إذا ظهر فشل في deploy راجعي الصلاحيات وإعداد Pages؛ لا تغيّري اسم المستودع أو base دون مراجعة المسارات وService Worker معًا.

## البيانات
التخزين LocalStorage. لتغيير الجهاز صدّري نسخة من لوحة المتابعة ثم استعيديها في الجهاز الجديد. لا تظهر النتائج تلقائيًا على جهاز المعلمة، ولا يوجد نظام صفوف أو حسابات. الحفظ قابل للفقد عند مسح بيانات المتصفح.

## قبل الاستخدام الصفي
أضيفي الأصول، وراجعي SOURCE-REVIEW.md وADDIE.md، وطبقي قائمة QA.md المرئية على هاتف وحاسوب. مراجعة المحتوى وفق الطبعة الثالثة الأصلية لازمة بسبب اختلاف عنوان طبعة النسخة العامة المكملة.
