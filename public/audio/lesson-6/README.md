# تسجيلات محطة الاستجابة

أضيفي التسجيلات الأصلية بصيغة MP3 أو OGG، ثم فعّلي مساراتها في src/data/audio.json وأعيدي النشر.

- intro.mp3: التهيئة
- explanation.mp3: الشرح
- simulation.mp3: تعليمات المحاكاة
- activity.mp3: تعليمات النشاط
- summary.mp3: الخلاصة

النص الموازي متاح داخل كل بطاقة صوت. لا ملفات صوتية بديلة أو صوت صناعي.
