# موسيقى اختيارية
island.wav لحن رقمي أصلي بسيط من ثماني نغمات جيبية، أُنتج لهذا المشروع برمجيًا، دون عينات أو لحن منقول. ليس تسجيلًا لصوت المعلمة ولا صوتًا بشريًا. التشغيل اختياري فقط، ودرجة الصوت الافتراضية 20%، والإيقاف وإعادة البداية متاحان. يمكن حذفه أو استبداله بتسجيل مرخص بعد تحديث المسار في AmbientMusic.tsx.
