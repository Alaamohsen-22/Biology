# صوت طبيعي للنموذج
لا توجد تسجيلات كلامية في المشروع حاليًا. لا يُستخدم speechSynthesis أو صوت آلي ضعيف أو وجه/صوت بديل للمعلمة.

أضيفي تسجيلات بشرية عربية قصيرة، أو ملفات أُنتجت بخدمة صوت طبيعي مرخصة بحسابك. الأسماء مرنة بحروف لاتينية وأرقام وشرطة. ابدئي من public/config/nutrition-voice.example.json، وانسخي فقط المقاطع الموجودة فعليًا إلى nutrition-voice.json. المسارات تبدأ audio/nutrition/، والنص موازي للتسجيل. لا تنسخي إعداد المثال قبل توفير الملفات.

الترحيب والتوجيهات بطول5–12 ثانية والتعزيز1–2 ثانية. MP3 أحادي64–96kbps كافٍ للكلام. لا تشغيل تلقائي؛ أزرار الاستماع تظهر بعد تحقق الملف، والشرح له أولوية على التعزيز والمؤثرات. لا تُحفَظ مفاتيح API في المشروع. إذا اختيرت خدمة TTS تحتاج حسابًا وموافقة على التكلفة؛ يمكن إنتاج الملفات خارج الموقع أو استخدام خادم وسيط يحفظ المفتاح. GitHub Pages لا يخفي الأسرار ولا يولد صوتًا من تلقاء نفسه.
