# مؤثرات أصلية
أنتجت للمشروع بموجات جيبية، بلا كلام أو عينات خارجية. select يجمع نقرة وحركة خفيفة؛ check للتحقق؛ error تنبيه لطيف؛ success لحن نجاح قصير. قناة واحدة توقف المؤثر السابق وتحترم الكتم ولا تبدأ تلقائيًا.

## النظام المركزي
أضيفت click/move/start/step/tool/water إلى الملفات الأصلية الأربعة، بموجات أصلية دون عينات خارجية. تدير sound.ts تشغيل الملفات عبر AudioContext بعد تفاعل المستخدم، مع مخزن مؤقت وقناة واحدة وكتم ومستوى صوت محفوظين. لا تعتمد المؤثرات على إعداد الحركة. لا يوجد صوت بشري مولد ولا بديل لتسجيلات المعلمة.

تطوير المختبر: أضيفت drop.wav (0.18 ثانية)، discover.wav (0.42 ثانية)، time.wav (0.24 ثانية)، مؤثرات رقمية أصلية أنشئت للمشروع بصيغة PCM أحادية القناة 22050 هرتز، دون تسجيل أو تقليد صوت بشري. ترتبط بالقطرات واكتشاف النتيجة وتقدم الزمن، ولا تمثل أصواتًا حقيقية للعمليات المجهرية الصامتة.

حُذفت مؤثرات فتح الكتاب وتقليب الورق مع إلغاء واجهة الكتاب. يبقى `diagnostic-result.wav` نتيجة تشخيصية محايدة لجميع الدرجات. مؤثرات أصلية مولدة محليًا، دون كلام أو عينات خارجية؛ تستخدم قناة المؤثرات المركزية وتحترم الكتم وأولوية السرد.

`bubble.wav` فقاعات الخميرة، و`combine.wav` و`separate.wav` اتحاد الوحدات وانفصالها. مؤثرات تعليمية أصلية قصيرة مولدة محليًا، وليست أصواتًا حقيقية للتفاعلات الجزيئية.
