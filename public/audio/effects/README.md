# مؤثرات أصلية
أنتجت للمشروع بموجات جيبية، بلا كلام أو عينات خارجية. select يجمع نقرة وحركة خفيفة؛ check للتحقق؛ error تنبيه لطيف؛ success لحن نجاح قصير. قناة واحدة توقف المؤثر السابق وتحترم الكتم ولا تبدأ تلقائيًا.

## النظام المركزي
أضيفت click/move/start/step/tool/water إلى الملفات الأصلية الأربعة، بموجات أصلية دون عينات خارجية. تدير sound.ts تشغيل الملفات عبر AudioContext بعد تفاعل المستخدم، مع مخزن مؤقت وقناة واحدة وكتم ومستوى صوت محفوظين. لا تعتمد المؤثرات على إعداد الحركة. لا يوجد صوت بشري مولد ولا بديل لتسجيلات المعلمة.
