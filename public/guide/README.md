# وسائط المرشدة المستقبلية
لا توجد مقاطع أو أصوات للشخصية حاليًا. لا يستدعي الموقع خدمة HeyGen أو API خارجيًا.

لإضافة ملفات منتجة لاحقًا، ضعيها في public/guide وعدلي public/config/guide-media.json. مثال مستقل لا يُفعَّل حتى إضافة ملف حقيقي:

```json
{
  "nutrition.intro": {
    "src": "guide/nutrition-intro.mp4",
    "kind": "video",
    "transcript": "النص الموازي",
    "cues": [{"start": 0, "end": 4, "text": "النص المتزامن"}]
  }
}
```
القيم المتاحة kind: audio أو video. مفاتيح بداية التغذية: nutrition.intro / nutrition.pre / nutrition.pre.result / nutrition.goals. مفاتيح بقية المراحل بصيغة lesson-رقم الدرس-رقم المرحلة (بدءًا من صفر)، مثل lesson-2-5 للمختبر. يمكن ضبط نص كل مرحلة في واجهتها الحالية دون كتابة مكون جديد.

الملف يُقرأ عند فتح الإرشاد فقط. تُفحص صلاحية رابط الوسائط قبل إظهار أزرارها، ولا تُحمّل الوسائط كاملة قبل طلب تشغيلها. تبقى الفقاعة عند غياب الملف. تقاسم القناة المركزية السرد مع صوت المعلمة، فتوقف الوسائط السابقة ولا تشغل الاثنين معًا. لا يبدأ الصوت تلقائيًا. إضافة ملف وتهيئته لا تتطلب تعديل الواجهة؛ نشر ملفات GitHub Pages بالطريقة المعتادة مطلوب، ثم تحديث الصفحة.

في فهرس المفاهيم الجديد، سياق المرشدة بصيغة `book-رقم الدرس-معرف الصفحة`، مثل `book-2-building-explain` أو `book-2-building-metabolism` أو `book-2-building-check`. معرفات الصفحات معرفة في `src/engine/lessonFlow.ts`. صفحات الإنفوجرافيك لا تنشئ مرشدة أو وسائط حتى لو وُضع مفتاح لها. إعدادات هذا المجلد ما زالت فارغة حاليًا ولا تضيف صوتًا تلقائيًا للشخصية.

بعد استعادة واجهة الموقع، بقيت أسماء سياق المرشدة التي تبدأ بـ book- للتوافق مع أي إعداد وسائط قديم فقط؛ لا يوجد إطار كتاب أو تقليب في واجهة الموقع.
